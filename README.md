# Japan Higher Study Management System

A local-first application for managing higher-study planning and related information.

## Development foundation

### Requirements

- Windows 10/11
- Node.js 24 LTS or later
- npm 11 or later

### Start locally

```powershell
Copy-Item apps\api\.env.example apps\api\.env
npm install
npm run dev
```

Open the Vite URL shown in the terminal (normally `http://127.0.0.1:5173`). The
frontend calls the API through its development proxy; the API listens on
`127.0.0.1:3001` by default.

### PostgreSQL migrations

Install PostgreSQL 14 or later locally, create an empty `hsms_dev` database,
copy `apps\api\.env.example` to `apps\api\.env`, and replace the example
database password with your local PostgreSQL password. Do not commit `.env`.
The API still binds to localhost; PostgreSQL should not be exposed to the LAN.

Apply or roll back one migration from the repository root:

```powershell
npm run migrate:up
npm run migrate:down
```

The migrations create users, roles, permissions, role assignments, hashed-token
session storage, and the initial student table. They also seed the Admin and
Staff roles with baseline permissions. Run rollback only when you intend to
remove the tables introduced by the migration and all data stored in them.

The API requires a valid PostgreSQL connection URL in `apps\api\.env`. Its
`/api/health` endpoint reports process liveness; `/api/ready` executes a
database query and returns HTTP 503 when PostgreSQL is unavailable. The server
drains HTTP requests and closes the connection pool during shutdown.

### Student records

After PostgreSQL is installed and the migrations have run, open the app to
search, filter, add, and edit student profiles. Internal student IDs are
generated by the API. No sample or synthetic student records are inserted into
your database.

Student data routes are currently available only through a server bound to a
loopback address. Login and server-side authorization have not yet been
implemented; do not expose this development app to a LAN or store real student
information until those protections are complete.

To run checks:

```powershell
npm test
npm run typecheck
npm run build
```

### Current scope and security boundary

This increment provides a React/TypeScript frontend, Express/TypeScript API,
PostgreSQL-backed student profile list/search/create/update routes, centralized
input validation and error handling, and API/database health endpoints.
Authentication, server-side authorization, education history, language tests,
and LAN access are not yet implemented. Keep both development servers bound
to localhost; do not expose them to a network.

The approved design is to add PostgreSQL, server-side authorization, secure
document storage, and LAN-only deployment in later increments. Database schema
work will follow the approved Phase 0 proposal.
